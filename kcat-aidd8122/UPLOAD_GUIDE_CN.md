# 上传 GitHub

1. 登录 GitHub，点击右上角 + → New repository。
2. 名称建议 kcat-aidd8122。课程要求链接可访问，可选择 Public；不要上传密码或服务器私密信息。
3. 创建仓库后选择 uploading an existing file / Add file → Upload files。
4. 解压下载包，进入 kcat-aidd8122 文件夹，把其中的 README.md、requirements.txt、core、experiments、results 等内容拖入上传页面，不要只上传 ZIP。
5. 检查文件列表，提交说明填写 Initial project code and results，再点击 Commit changes。文件较多可分批上传目录。
6. 用未登录窗口检查仓库可访问，将仓库网页地址发回聊天，用于补入报告。

当前包不含原始数据、模型权重、缓存和大预测表。README 说明如何获得数据和重跑。报告 Word 可在检查后另放入 reports/；最终课程仍要求 PDF。
